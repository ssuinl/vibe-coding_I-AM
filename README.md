# 독립러의 밥상

개인 식탁을 사진과 짧은 글로 기록하는 정적 웹페이지입니다.

## 주요 구성
- 혼자 먹는 밥상과 함께 나누는 식탁의 사진 카드
- 화면 크기에 대응하는 레이아웃
- 좋아요, 방명록 입력 등 브라우저 내 인터랙션

## 실행 방법
`I AM_suin.html`을 브라우저에서 열면 됩니다. 외부 CDN 리소스를 불러오려면 인터넷 연결이 필요할 수 있습니다.

## 구현 범위
HTML, CSS, Tailwind CSS, JavaScript 기반의 개인 웹 제작 실습입니다. 별도 백엔드나 서버 저장 기능을 제공하지 않습니다. 사진은 개인 기록물입니다.
